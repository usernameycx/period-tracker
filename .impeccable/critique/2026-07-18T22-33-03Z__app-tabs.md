## Priority Issues

### P0 — Calendar grid alignment (FIXED)
CalendarView.tsx day cells used 13.5% width + 2px margins vs weekdays using flex:1. Fixed by chunking days into rows of 7 with flex:1 per cell.

### P0 — Design token inconsistency (FIXED)
CalendarView, CityPicker, LunarCard, SymptomPicker, DietCard, StatsCard had hardcoded colors. Replaced all with theme tokens. Added LunarColors for traditional almanac palette.

### P1 — Time picker (FIXED)
Replaced ▲▼ arrow picker with native DateTimePicker via @react-native-community/datetimepicker.

### P1 — Android import dead-end (FIXED)
Added Modal+TextInput for JSON paste import on Android.

### P2 — CycleStatusCard prominence (FIXED)
Changed from sharedCard.base to sharedCard.prominent. Progress bar 4px→6px, color improved.

### Minor (FIXED)
DailyQuoteCard shadow now uses theme default. Settings page title spacing uses Spacing token.
