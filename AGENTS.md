# FayeTide — Period Tracker App

Expo SDK 57 · React Native 0.86 · TypeScript · SQLite

## What is this app

A period/cycle tracker for Chinese users. Tracks menstrual cycles, predicts phases (period/follicular/ovulation/luteal), logs daily symptoms, provides lunar calendar + weather-aware life advice.

## Tech Stack

| Layer | Technology |
|-------|-----------|
| Framework | Expo SDK 57 (managed → bare workflow) |
| UI | React Native 0.86 + expo-router |
| Language | TypeScript ~6.0 |
| Database | expo-sqlite (local SQLite) |
| Navigation | expo-router (file-based tabs) |

| Icons | Custom react-native-svg components |

## Critical: Native Project Committed

`android/` is **committed to git** (NOT in .gitignore). This was done to customize the native splash screen. EAS Build uses the committed native files directly.

**Consequences:**
- `app.json` must NOT have `splash`, `orientation`, `icon`, `scheme`, `userInterfaceStyle`, `plugins`, `ios`, `android` as root keys — EAS ignores them when `android/` exists
- Native splash is configured in `android/app/src/main/res/drawable/splash_bg.xml` + `values/styles.xml` + `values/colors.xml`
- `expo-splash-screen` package handles JS-side splash control (preventAutoHideAsync/hideAsync in `app/_layout.tsx`)
- `eas.json` preview profile uses `buildType: "apk"` without custom gradleCommand

## Phase Prediction Logic

`DEFAULT_PERIOD_DAYS = 5`, `DEFAULT_CYCLE_DAYS = 28`, `OVULATION_BEFORE_PERIOD = 14`

1. `getPhaseForCalendarDay(date, records)` — maps a date to a phase using recorded cycle starts. Returns null if date is outside all known cycles.
2. `useCurrentPhase()` — calculates today's phase. First tries `getPhaseForCalendarDay`, then falls back to `getPhaseForDate` predictive model.
3. One record = one cycle predicted forward. Dates before the first record or beyond the predicted cycle end return null.
4. `useCurrentPhaseOrDefault()` — returns null when no data covers today. CycleStatusCard shows a placeholder card in this case.

All icons defined in `src/components/Icon.tsx` as SVG paths in 24×24 viewBox. Each symptom has a **unique** icon:

| Mood | 开心/平静/烦躁/难过/焦虑 | smile/zen/storm/frown/nervous |

Mappings live in `SymptomPicker.tsx` CATEGORIES/TOGGLES arrays.

## Key Design Decisions / Recent Fixes

1. **Splash screen**: Native splash uses `splash_bg.xml` (layer-list: #F8F2EA bg + centered splashscreen_logo). JS-side `preventAutoHideAsync()` + 3s delay in `_layout.tsx`.
2. **Calendar today mark**: Today is auto-selected on mount. Selection style is black border + bold text. No separate today style.
3. **Week strip**: Always shows current system week, not affected by user selection. Read-only display.
4. **Tab return reset**: All 3 tabs use `useFocusEffect` to scroll to top on re-focus. Calendar also resets selectedDate and currentMonth.
5. **Phase countdown logic**: When `phase === 'period'`, always show "进行中 经期第N天" (use dayOffset directly). Otherwise use daysUntilPeriod for countdown.
6. **Ovulation countdown during period**: `computeCountdowns` separates period from follicular — uses dayOffset for period (14 - dayOffset days until ovulation).
7. **CycleStatusCard error**: Uses `ConfirmModal` instead of system `Alert.alert()` for consistency.
8. **Can't predict backwards**: `useCurrentPhase` returns null if today is before the first recorded cycle start.
